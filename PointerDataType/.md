## 4. What Does the `*` Operator Do in Go When Used with a Pointer?

The `*` operator is used for **pointer dereferencing**, meaning it retrieves or modifies the value stored at the memory address that the pointer points to.

### Example: Dereferencing a Pointer
```go
package main

import "fmt"

func main() {
    var num int = 42
    var ptr *int = &num // Pointer to num

    fmt.Println("Address of num:", ptr)  // Prints the memory address
    fmt.Println("Value at ptr:", *ptr)   // Dereferencing (prints 42)

    // Modifying the value using a pointer
    *ptr = 100
    fmt.Println("Updated num:", num) // num is now 100
}
``` 
### &num gives the memory address of num.
### It is used to create pointers.
