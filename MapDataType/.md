## How It Differs from Array and Slice

| Feature      | Map                  | Array              | Slice              |
|-------------|---------------------|-------------------|------------------|
| Structure   | Key-Value pairs     | Fixed-size list   | Dynamic list     |
| Index Type  | Any type (string, int, etc.) | Only Integer Index | Only Integer Index |
| Size        | Dynamic            | Fixed            | Dynamic         |
| Order       | Unordered         | Ordered         | Ordered        |
| Access      | Access by Key     | Access by Index | Access by Index |

### make() only takes the map type without curly braces {}.

#### value, exists := map[key]
**value:** Stores the value associated with the key.

**exists:** Returns true if the key is present, otherwise false.
