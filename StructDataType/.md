# Structs in Go

## What is a Struct in Go?
A **struct** in Go is a composite data type that groups together variables under a single name. These variables, known as **fields**, can have different types. Structs are commonly used to create custom data structures.

## Declaring a Struct
To define a struct, use the `type` keyword followed by the struct name and its fields inside curly braces.

```go
package main

import "fmt"

// Defining a struct
type Person struct {
    Name string
    Age  int
    City string
}

func main() {
    // Creating an instance of the struct
    p := Person{Name: "Alice", Age: 30, City: "New York"}
    fmt.Println(p)
}
```

## Accessing Struct Fields
You can access struct fields using the **dot notation (`.`)**.

```go
fmt.Println(p.Name) // Output: Alice
fmt.Println(p.Age)  // Output: 30
```

## Initializing Structs
There are multiple ways to initialize a struct:

### Using Field Names
```go
p1 := Person{Name: "Bob", Age: 25, City: "San Francisco"}
```

### Without Field Names (Positional Order)
```go
p2 := Person{"Charlie", 40, "Chicago"}
```

### Using `new` Keyword
```go
p3 := new(Person) // Returns a pointer to a zero-initialized struct
p3.Name = "David"
p3.Age = 35
p3.City = "Los Angeles"
```

## Struct with Methods
Structs can have methods associated with them.

```go
type Rectangle struct {
    Width, Height float64
}

// Method to calculate area
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

func main() {
    rect := Rectangle{Width: 5, Height: 10}
    fmt.Println("Area:", rect.Area())
}
```

## Pointers to Structs
Using pointers with structs allows modifying struct values without copying them.

```go
func (p *Person) UpdateAge(newAge int) {
    p.Age = newAge
}

func main() {
    p := Person{Name: "Eve", Age: 22, City: "Boston"}
    p.UpdateAge(23)
    fmt.Println(p.Age) // Output: 23
}
```

## Anonymous Structs
Anonymous structs allow quick struct usage without defining a separate type.

```go
user := struct {
    Username string
    Email    string
}{
    Username: "john_doe",
    Email:    "john@example.com",
}
```

## Conclusion
Structs in Go provide a way to define and work with complex data types. They support methods, pointers, and embedding, making them powerful building blocks for Go applications.
